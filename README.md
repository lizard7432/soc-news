# 資安新聞交班台

供公司 SOC 同事透過網頁自動蒐集、整理與匯出繁體中文資安新聞。Docker Compose 單一服務，SQLite 持久儲存，本機 CPU 語意模型，不需要付費 AI API。

## 部署

1. 將此資料夾放到公司伺服器，需有 Docker Engine 與 Docker Compose v2。
2. 不需要帳號密碼。只有要調整綁定位址或班別時，才需複製 `.env.example` 為 `.env`。
3. 在資料夾內執行：

```sh
docker compose up -d --build
docker compose logs -f --tail=100
```

4. 預設只在伺服器的 `http://127.0.0.1:7879` 提供服務。將公司 HTTPS 反向代理轉到此位址，再提供公司內部網址給同事。
5. 開啟網頁後查看右側「蒐集狀態」。首次啟動會下載約數百 MB 的模型；完成後自動進行首次蒐集，之後每個整點再跑一次。

若公司反向代理在另一部機器，可將 `BIND_ADDRESS` 改為伺服器的內網 IP。依需求已移除平台登入，能連到平台的同事即可操作；操作紀錄統一標示 internal-user。

伺服器需能對新聞來源、套件來源與模型來源連外。模型下載完成後保存在 `soc-models` volume；推論在本機執行，不將新聞內容送到外部 AI 服務。

目前已驗證本機 Python 服務；製作環境沒有 Docker，因此**尚未執行容器建置或公司伺服器部署**。建議公司先以 2 CPU、4 GB RAM 做試運行，再依實際新聞量調整；此數值不是容量測試結果。

## 操作

## 開不起來時先確認

- ZIP 是部署原始碼，不能直接雙擊當成網站。請先解壓，再執行 Docker Compose。
- 顯示 Docker daemon 無法連線：先啟動 Docker 服務，再重跑 `docker compose up -d --build`。
- 在伺服器上開 `http://127.0.0.1:7879/health` 應看到 `{"ok":true}`。首頁直接顯示新聞列表，不要求登入。
- 同事電腦的 `127.0.0.1` 是同事自己的電腦。正式使用請開公司 HTTPS 反向代理網址，不能使用同事電腦的 localhost。
- 預設 `BIND_ADDRESS=127.0.0.1` 只允許伺服器本機存取。如需從內網反向代理連入，依上節設定內網 IP 及防火牆；修改後重跑 `docker compose up -d`。
- 查看實際錯誤：`docker compose ps` 與 `docker compose logs --tail=100`。提供錯誤訊息時，不必附上 `.env` 密碼。

## 操作步驟

1. 每小時自動蒐集，也可按「立即蒐集」。
2. 選日期與班別，自動顯示通過原文、時間及去重檢查的新聞，可直接複製或下載。
3. 「新聞管理（選用）」可修改、排除、合併或拆分事件。暫緩新聞不影響其他新聞產出。
4. 如需記錄交班，按「產生預覽」；不用勾選或人工核准，系統自動選用本班合格新聞。
5. 複製或下載 TXT，完成實際交班後才按「確認已交班」。預覽、複製及下載本身不會更動交班狀態。

輸出範例：

```text
115年9月5日-日班-資安相關新聞列表：

醫院資安新制 院長不得任意查病歷
https://udn.com/news/story/7266/9735651
```

範例由需求提供，不會當作假新聞填入資料庫。

## 排程與班別

- 時區固定為 `Asia/Taipei`，資料庫時間使用 UTC。
- 啟動時補抓最近 3 天內的 RSS 項目，之後每整點蒐集。來源未提供可驗證發布時間者只能待處理，不能列入交班。
- 新聞列表截止／產出時間：日班 11:00、小夜班 19:00、大夜班 03:00。
- 對應八小時區間：日班 03:00–11:00、小夜班 11:00–19:00、大夜班當日 19:00–隔日 03:00。這是新聞區間，不是人員上下班時間。
- `.env` 使用 `SHIFT_REPORT_HOURS=11,19,3` 及 `SHIFT_NAMES=日班,小夜班,大夜班`。舊版 `SHIFT_STARTS` 請替換為 `SHIFT_REPORT_HOURS`。
- 列表日期依班別所屬日：日班與小夜班為當日；大夜班為凌晨產出日的前一日。例如 9 月 5 日凌晨 3 點產出「115年9月4日-大夜班」。日期選擇器輸入的是班別所屬日。
- 頁面預設選取下一個產出時刻。此設定控制列表日期與新聞截止範圍；目前仍由同事按鍵預覽、下載及確認交班，沒有在該時刻自動凍結或推送報表。
- 列表與匯出嚴格依原始發布時間，採「起點不含、終點包含」。日班當日03:00之後至11:00；小夜班11:00之後至19:00；大夜班當日19:00之後至隔日03:00。不使用收錄時間、不補入積欠舊聞、不以修改時間冒充發布時間。日期不明、只有日期缺少時刻者不列入。
- 單一容器、單一 Uvicorn worker。不要增加 replica 或 workers，否則排程會重複。排程執行中不重疊；若一輪超過一小時，完成後等下一個整點。

## 去重方式與限制

1. **網址去重**：移除常見追蹤參數，再以唯一網址避免重抓。
2. **語意去重**：使用 `sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2` 比對 RSS 標題和摘要，搜尋最近 14 天、最多 500 篇候選新聞。
3. 先去除媒體尾綴與標點，再核對共同主體、事件行為和金額／數量。主體、行為與關鍵事實一致時，語意相似度達 0.76 可合併改寫報導；不符合這條規則時才使用原本 0.94 的高相似門檻。0.82 以上未合併者列為候選。相似度不是正確率。
4. 只將具單位的數量、金額及 CVE 視為事實；「1關鍵」等編號不視為變更。相同單位的數量衝突、相隔超過 72 小時、具體調查／修補進展不同時保留審核。「證實」或「警示」本身不構成新進展。主體核對目前依標題共同前綴等規則，並非完整實體辨識；主詞位置不同的報導仍可能需要人工確認。
5. 模型載入失敗會明確顯示降級狀態，改用中文字元比對。此時無法可靠辨識大幅改寫，請人工審核。可用 `SEMANTIC_ENABLED=false` 明確停用模型。

本版本不宣稱完全理解事件：只比對 RSS 標題與摘要，**尚未擷取所有媒體全文，也沒有嚴格的事件實體核對**。例如同類型攻擊但受害公司不同，仍有誤判風險；所有來源保留，可拆分修正。若要提高準確率，應以真實交班資料標註同事件／不同事件，再調整門檻或增加實體核對。

## 新聞來源與範圍

- [iThome RSS](https://www.ithome.com.tw/rss)：讀取 RSS 後以資安關鍵詞篩選。
- Google 新聞 RSS：以繁體中文介面搜尋全球資安報導，搜尋條件不再限制台灣。`gl=TW` 是新聞語系／市場偏好，不代表事件必須在台灣。
- **不做簡轉繁。** RSS 標題或摘要含可辨識簡體字時拒收；既有資料不再進行轉換顯示。
- 分享前檢查媒體原始頁面正文及語言標示。檢出簡體、原文無法讀取、正文無法定位、非允許來源或語言不明者均不能分享。檢查有效期為 24 小時；原始網站仍可能於檢查後變更。
- 來源允許清單在 `app/source_policy.py`，仍須通過原文檢查。中文姓名與共用字存在歧義，檢查偏保守，可能誤擋；這不是語言辨識百分之百正確的保證。不能用轉繁體或人工輸入理由解除來源限制。
- Google RSS 只作為發現新聞的來源。目前不能可靠還原的 Google 包裝連結一律待處理，不進入分享列表，也不提供可點擊連結。要擴大覆蓋，需加入媒體直接 RSS／原文解析，不能把 Google 繁體介面當成原文語言證明。
- 來源目前為程式內設定；沒有網站後台任意新增 URL 的功能。
- RSS 可能不完整、延遲或中斷；來源成功但新增 0 篇與來源失敗會分別顯示。無法保證涵蓋所有台灣新聞。
- 此工具保存來源提供的標題、摘要與連結，沒有繞過付費牆。

模型支援參考：[FastEmbed 官方文件](https://qdrant.github.io/fastembed/examples/Supported_Models/)。

## 資料與備份

- `soc-data` volume：SQLite 資料庫、新聞、審核、交班及操作紀錄。
- `soc-models` volume：下載的模型。
- `docker compose down` 會保留資料；不要加 `-v`，以免刪掉 volume。
- 可使用 SQLite 線上備份取得一致快照，再複製到備份位置：

```sh
docker compose exec soc-news python -c "import sqlite3; src=sqlite3.connect('/data/soc.db'); dst=sqlite3.connect('/data/backup.db'); src.backup(dst); dst.close(); src.close()"
docker compose cp soc-news:/data/backup.db ./soc-backup.db
```

## 開發驗證

```sh
python -m venv .venv
# Linux: source .venv/bin/activate
# Windows PowerShell: .venv/Scripts/Activate.ps1
python -m pip install -r requirements.txt pytest
python -m pytest -q
```

測試使用獨立暫存資料庫；語意路由測試使用固定向量，不代表模型在真實新聞上的準確度。測試範圍包括追蹤參數去重、語意合併路由、數字變更保留、合併拆分、登入、來源失敗、民國日期、跨午夜班別與跨班交班。

## 更新既有待審核資料

新版去重會套用在新收到的新聞。已收錄資料可先預覽重新分群結果，再套用：

`sh
docker compose exec soc-news python -m app.recluster
docker compose exec soc-news python -m app.recluster --apply
`

套用前會備份 SQLite，保留來源與合併紀錄。只處理待審核、未交班且未曾人工編輯／合併／拆分的事件；不覆寫同事已做的判斷。

## 新聞列表畫面

首頁優先顯示「民國日期-班別-資安相關新聞列表」、每則標題及連結，可複製或下載 TXT。列表外會標示待審核數量；複製與下載不代表完成交班。全球資安事件均可列入。下方展開「審核與整理新聞」仍可編輯、合併與拆分。

## 分享前的嚴格審核

- 標題獨立語意向量相似度 ≥ 0.72，或標題字元相似度 ≥ 0.23 的不同事件會被標為疑似重複。這是攔截門檻，不是自動合併門檻，也不是正確率。
- 疑似重複者從列表、複製與下載內容移除；後端亦阻止匯出，即使之前曾被核准也會重新攔截。
- 按「處理暫緩新聞」可集中查看。相同事件請合併；不同事件／實質新進展須說明具體差異（至少 10 字），留存紀錄後才可核准。此理由是人工判斷，不由模型保證正確。
- 來源檢查與重複檢查結果以同一批提交，避免來源先通過、重複檢查尚未完成的空窗。
- 本版本沒有宣稱能自動識別所有改寫。更寬的攔截會增加人工審核量；未知來源會造成可分享新聞數量下降。

## 發布時間核對

使用媒體原文的 datePublished／article:published_time，要求完整時刻與時區，忽略 dateModified。iThome 原文只顯示日期，因此只在其官方 RSS 的發布時間與原文日期一致時採用該時間；Google RSS 的日期不作為原文發布證據。資料庫的 original_published 是通過核對的時間。待審核與可交班預設亦限本班；歷史資料可在「全部（歷史）」查看，不會補入當班列表。


Google 新聞連結會先使用 googlenewsdecoder 解析成媒體網址，再檢查原文語言與發布時間。資料庫保留原始收錄網址及 resolved_url；解析結果可重用。解析逾時、網站阻擋及不支援媒體會保留原因，不會視為簡體。

媒體擷取擴充：支援現有收錄涉及的媒體，優先讀取正文專屬元素與 JSON-LD articleBody，再以正文抽取備援；不以 RSS 摘要代替原文。HTTP 403/404/405 會顯示明確原因。升級後會重新檢查未確認資料。


自動產出模式：通過原文語言、時間、去重檢查的新聞無須人工核准即可列入交班與匯出。未選取事件時預覽自動使用本班合格新聞；疑似重複、排除與來源不明仍攔截。人工管理為選用，不影響其他新聞產出。48項測試通過，含無人工核准匯出與攔截回歸測試。


## 蒐集入口（目前8個）
iThome、科技新報、中央社科技／國際／社會五個直接RSS，加上Google一般資安／漏洞修補／攻擊外洩三組搜尋。升級時加入新增來源，保留已存在來源的停用設定，避免重複建立。新聞來源的RSS时间只是候選資料，交班仍以原文發布時間為準。

## 網域優先語言政策
繁體媒體採明確網域清單；多語網站以繁體版本路徑確認。這些來源不因個別字形差異被攔截。網址或HTML明確標記zh-CN、zh-Hans、gb等簡體版本仍排除，未知來源保留用字檢查。Google先解析媒體網址，不能以Google網域判定語言。原文正文、發布時間、去重限制仍適用，不進行簡轉繁。


### 自選交班時段（新版）
班別為日班、小夜班、大夜班，只用於標題。網頁可自行設定開始／結束日期時間（台灣時間），預設最近24小時，不再限制固定八小時。範圍採開始不含、結束包含，可跨日補收前班遺漏新聞。確認交班才會標記已交班；複製與下載不會。API 可傳 start/end；未傳者保留舊版預設時段相容行為。


## 網頁來源與關鍵字管理（2026-09-07）
在「蒐集狀態與操作紀錄」內新增「資料來源管理」與「關鍵字管理」。
- 來源可新增、測試、啟用或停用，設定保存於 SQLite。接受支援網域的 RSS／Atom；可展開網域清單。未知網域仍須開發者擴充原文解析與政策，不能藉新增訂閱繞過來源限制。
- 訂閱請求限制標準 HTTP(S) 連接埠、公開 IP、4 MB 大小及轉址次數；每次轉址重新檢查並將連線固定至已驗證 IP。
- 搜尋關鍵字控制 Google 新聞查詢，預設彙整原本三組搜尋詞。多個 Google 入口每輪只執行第一個啟用入口，使用共同關鍵字；其他入口設定保留。刪除全部搜尋詞會暫停 Google 搜尋，不影響媒體 RSS。
- 排除詞以標題或摘要的不分大小寫子字串比對，套用新收錄與既有新聞分享資格。刪除排除詞解除限制，但不保證補抓歷史新聞。原有資安相關性與原文政策仍然生效。
- 來源與搜尋詞下次蒐集生效；正在執行的蒐集使用該輪啟動時的設定。所有可存取此免登入平台的人都可修改設定，操作會留下紀錄。
- 新增的設定與回歸測試通過，共73項。已實測 iThome RSS 與瀏覽器關鍵字新增／刪除、來源測試。
